# Laboratory 01 — Welcome to the Cloud

## Mission Overview

This laboratory activity introduces me to a cloud computing environment through hands-on work with Linux and GitHub. The activity allows me to practice working in a cloud-based terminal, managing files and directories, gathering system information, and documenting my work.

## Objectives

- Become familiar with a cloud-based Linux environment
- Practice using Linux terminal commands
- Learn how to create and manage files and directories
- Gather basic system information
- Document laboratory activities using Markdown
- Organize and maintain a cloud computing portfolio using GitHub

## Activities Performed

During this laboratory activity, I:

1. Created and configured my Linux user account.
2. Verified my username, home directory, and hostname.
3. Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
4. Created and organized my workspace.
5. Created and documented my `about-me.md` file.
6. Created a GitHub repository for my Cloud Computing portfolio.
