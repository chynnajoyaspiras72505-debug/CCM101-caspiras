# Cloud Infrastructure Components

## Compute

Compute provides the processing power needed to run applications and workloads in the cloud. In the KillerCoda environment, the virtual machine uses one Intel Xeon virtual CPU.

## Memory

Memory provides temporary storage for data and programs currently being processed. The KillerCoda environment has 1.9 GiB of total memory.

## Storage

Storage provides persistent space for files, applications, and system data. The main filesystem in the KillerCoda environment is `/dev/vda1`, with a total size of 19 GB.

## Networking

Networking allows cloud resources to communicate with other systems and services. It enables connections between virtual machines, applications, users, and the internet.

## Virtualization

Virtualization allows physical computing resources to be divided into virtual machines. The KillerCoda environment uses KVM as its hypervisor and runs with full virtualization.

## Operating System

The operating system manages the hardware and software resources of the virtual machine. The KillerCoda environment is running Ubuntu 24.04.4 LTS.

## Summary

These components work together to form the foundation of cloud infrastructure. Compute handles processing, memory supports active workloads, storage keeps data, networking provides connectivity, virtualization enables virtual machines, and the operating system manages the environment.
