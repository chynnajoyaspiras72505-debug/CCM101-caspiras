# Reflection

This laboratory activity helped me understand the basic components that make up cloud infrastructure. By examining the KillerCoda Linux environment, I was able to identify its operating system, CPU, memory, storage, and virtualization technology.

I also learned that cloud providers such as AWS, Microsoft Azure, and Google Cloud offer similar infrastructure services even though they use different service names. This activity helped me understand how compute, storage, networking, virtualization, and operating systems work together to create a cloud environment.

Overall, the activity improved my understanding of Linux-based cloud infrastructure and the importance of documenting technical information using Git and GitHub.
