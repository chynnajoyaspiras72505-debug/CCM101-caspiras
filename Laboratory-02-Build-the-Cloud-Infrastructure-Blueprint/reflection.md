# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think networking is one of the most important cloud infrastructure components because it connects users, applications, servers, and cloud services. Even if compute and storage resources are available, they cannot be useful to remote users without reliable network connectivity.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, flexible, and efficient operating system for servers and virtual machines. Many cloud platforms use Linux because it is highly configurable, supports automation tools, and works well with containers, networking, and server applications.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation helps teams understand the planned infrastructure, its resources, configuration, and dependencies. It can reduce mistakes during deployment and makes troubleshooting, maintenance, and future upgrades easier.

## 4. What new skills did you learn during this laboratory activity?

During this activity, I learned how to investigate a Linux server using commands such as `uname`, `lscpu`, `free`, `df`, `hostname`, and `ip addr`. I also improved my skills in Markdown documentation, Git commits, GitHub pushing, and comparing services from AWS, Azure, and Google Cloud.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio now contains a more organized cloud computing laboratory project with technical documentation and infrastructure analysis. It shows that I can investigate a Linux environment, document system information, compare cloud services, and maintain my work using Git and GitHub.

Overall, this mission helped me understand how cloud infrastructure is built from several connected components. I learned that compute, storage, networking, operating systems, and identity services all work together to support cloud applications.
