# Mission Reflection

I think networking is one of the most important components of cloud infrastructure because it connects users, applications, servers, and cloud services. Compute and storage resources may be available, but without reliable network connectivity, users and systems would not be able to communicate with them effectively. This activity helped me understand that the different components of cloud infrastructure depend on one another to provide functional cloud services.

Linux supports cloud computing by providing a stable, flexible, and efficient operating system for servers and virtual machines. During this laboratory, I used Linux commands such as `uname`, `lscpu`, `free`, `df`, `hostname`, and `ip addr` to investigate the system. This experience showed me why Linux is commonly used in cloud environments and also helped me become more comfortable working through the command line.

I also learned why technical documentation is important before deploying infrastructure. Documentation provides information about the planned resources, configurations, and dependencies of a system. Having these details prepared can help reduce deployment mistakes and make troubleshooting, maintenance, and future changes easier.

During this laboratory activity, I developed practical skills in investigating a Linux environment and documenting technical information using Markdown. I also improved my understanding of cloud infrastructure components and compared services from AWS, Azure, and Google Cloud. In addition, I practiced using Git commands to save my work and push changes to GitHub.

Completing this mission also improved my GitHub portfolio because it now contains organized technical documentation showing the work I completed during the laboratory. It demonstrates my experience with Linux commands, cloud infrastructure concepts, cloud service comparisons, Markdown documentation, Git, and GitHub. Overall, the activity gave me a better understanding of how cloud infrastructure components work together and helped me build practical skills that I can continue developing in future laboratory activities.
