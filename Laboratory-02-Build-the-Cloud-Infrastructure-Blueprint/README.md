# Laboratory Activity 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This mission explores the basic components of cloud infrastructure using a Linux environment in KillerCoda. It includes server investigation, cloud component identification, cloud provider comparison, and infrastructure documentation.

## Objectives

- Investigate a Linux server in a cloud environment.
- Identify major cloud infrastructure components.
- Compare AWS, Microsoft Azure, and Google Cloud Platform services.
- Create a simple cloud infrastructure design.
- Practice Git, GitHub, Linux commands, and Markdown documentation.

## Cloud Infrastructure Components

The major components studied in this activity are compute resources, storage resources, networking resources, operating systems, and identity and access management.

## Skills Learned

I learned how to inspect a Linux cloud server, identify system resources, document infrastructure information, compare cloud providers, and use Git and GitHub to manage technical documentation.

## Challenges Encountered

One challenge was configuring Git authentication and the Git user identity in the temporary KillerCoda environment. I also had to carefully organize the required files and collect accurate system information before documenting the results.
