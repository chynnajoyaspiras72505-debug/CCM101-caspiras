# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud |
| Identity and Access Management | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is commonly recognized for offering a very broad range of cloud services across compute, storage, databases, networking, analytics, security, and many other areas. Its large service catalog makes it suitable for many different types of organizations and workloads.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure is a strong choice for organizations that primarily use Microsoft products. It integrates closely with technologies such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise tools.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud Platform is widely recognized for its strengths in artificial intelligence, machine learning, data analytics, and Kubernetes. Google originally developed Kubernetes, and GCP provides strong managed Kubernetes services through Google Kubernetes Engine.

### 4. What similarities did you observe among the three cloud providers?

AWS, Microsoft Azure, and Google Cloud Platform all provide core services for compute, storage, networking, and identity management. Although the service names are different, they solve many of the same infrastructure problems.
