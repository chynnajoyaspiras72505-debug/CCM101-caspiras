# Cloud Provider Comparison

| Cloud Component | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud |
| Database | Amazon RDS | Azure SQL Database | Cloud SQL |

## Summary

AWS, Microsoft Azure, and Google Cloud provide similar core cloud infrastructure services. Although their service names are different, each provider offers compute, storage, networking, and database solutions that organizations can use to build cloud infrastructure.
