# Automation Research

## Bash Script

A Bash script is a text file containing a sequence of commands that can be executed by the Bash shell. It is useful for cloud operations because it can automate repetitive tasks such as creating directories, copying files, and performing backups.

## Variables

Variables are used to store values that a script can reuse during execution. For example, using a variable such as BACKUP_DIR makes a script easier to manage because the same value can be referenced without typing the exact path multiple times.

## Cron Job

A cron job is a scheduled task in Linux that automatically runs a command or script at a specified time. It is essential for cloud operations because it can perform recurring tasks such as backups without requiring a person to run the command manually.
