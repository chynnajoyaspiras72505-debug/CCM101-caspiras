Learning cloud technologies allows me to build on my existing networking foundation while developing a broader understanding of infrastructure, security, scalability, virtualization, and cloud-based services.

My goal is to continue improving my technical skills, become more confident in working with different technologies, and prepare myself for opportunities in the IT industry. I am especially interested in discovering how I can combine my knowledge of networking and cloud computing as I continue developing my career.

This journey is not only about completing course requirements, but also about challenging myself to learn unfamiliar technologies, gain practical experience, and discover how far I can grow as an IT professional.
