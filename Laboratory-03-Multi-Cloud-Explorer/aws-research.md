# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform that provides on-demand computing, storage, networking, database, and other cloud services. It allows organizations to build and run applications without maintaining all physical infrastructure themselves.

## Global Infrastructure
AWS operates through geographic Regions that contain multiple Availability Zones. This structure helps organizations deploy applications closer to users while improving availability and reliability.

## Cloud Management Console
The AWS Management Console is a web-based interface used to access, configure, and manage AWS cloud resources and services.

## Four Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers for running applications and workloads.
2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for files, backups, and application data.
3. **Amazon VPC (Virtual Private Cloud)** – Provides an isolated virtual network for AWS resources.
4. **AWS IAM (Identity and Access Management)** – Manages users, roles, permissions, and access to AWS resources.

## Three Advantages
1. **Scalability** – Resources can be increased or decreased based on workload requirements.
2. **Global Reach** – AWS has cloud infrastructure across many geographic locations.
3. **Wide Service Selection** – AWS provides services for computing, storage, networking, databases, analytics, AI, and other workloads.

## Typical Enterprise Use Cases
- Hosting websites and enterprise applications
- Data backup and disaster recovery
- Cloud storage and databases
- Application development and testing
- Data analytics and machine learning
- Running scalable virtual servers
