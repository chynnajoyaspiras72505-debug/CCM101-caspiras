# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, and application development.

## Global Infrastructure
GCP organizes its infrastructure into regions and zones located around the world. This allows organizations to deploy applications across multiple locations for better availability, reliability, and performance.

## Cloud Management Console
The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services
1. **Compute Engine** – Provides scalable virtual machines for running applications and workloads.
2. **Cloud Storage** – Provides object storage for files, backups, media, and application data.
3. **Virtual Private Cloud (VPC)** – Provides networking capabilities for connecting and protecting cloud resources.
4. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for deploying and managing containerized applications.

## Three Advantages
1. **Data Analytics** – GCP provides powerful services for processing and analyzing large amounts of data.
2. **AI and Machine Learning** – Google Cloud provides tools and services for building and deploying AI and machine learning solutions.
3. **Global Infrastructure** – Google's worldwide infrastructure supports scalable and highly available applications.

## Typical Enterprise Use Cases
- Artificial intelligence and machine learning
- Big data analytics
- Hosting websites and applications
- Running virtual machines
- Kubernetes and containerized applications
- Data storage and backup
