# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, and application development.

## Global Infrastructure
Azure operates through geographic regions and Availability Zones around the world. This global infrastructure allows organizations to deploy applications closer to their users and improve availability and reliability.

## Cloud Management Console
The Azure Portal is a web-based management console that allows users to create, configure, monitor, and manage Azure resources and services.

## Four Core Services
1. **Azure Virtual Machines** – Provides scalable virtual servers for running Windows and Linux workloads.
2. **Azure Blob Storage** – Provides object storage for files, backups, media, and other unstructured data.
3. **Azure Virtual Network** – Provides private networking for Azure resources and services.
4. **Microsoft Entra ID** – Provides cloud-based identity and access management for users and applications.

## Three Advantages
1. **Microsoft Integration** – Integrates well with products such as Windows Server, Microsoft 365, and Microsoft Entra ID.
2. **Hybrid Cloud Support** – Supports organizations that combine on-premises infrastructure with cloud services.
3. **Scalability** – Computing and storage resources can be adjusted according to changing business requirements.

## Typical Enterprise Use Cases
- Hosting Windows and Linux virtual machines
- Enterprise application hosting
- Data storage and backup
- Hybrid cloud deployments
- Identity and access management
- Artificial intelligence and data analytics
