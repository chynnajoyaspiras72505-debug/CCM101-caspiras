| Ideal Organizations | Enterprises needing a broad range of scalable cloud services | Organizations already using Microsoft technologies | Organizations focused on data, AI, ML, and cloud-native applications |

## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the broadest range of cloud services among the three providers. Its mature ecosystem covers computing, storage, networking, databases, analytics, security, artificial intelligence, and many specialized enterprise services.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft enterprise products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform is particularly strong in artificial intelligence, machine learning, and Kubernetes. Google's experience with AI technologies and its development of Kubernetes make GCP a strong platform for data-driven and cloud-native applications.

### 4. Which cloud platform would you personally choose and why?
I would choose AWS because of its broad selection of services, mature ecosystem, and flexibility for different types of workloads. Its extensive cloud infrastructure and service portfolio would also give me opportunities to learn technologies that are widely used in cloud computing.
