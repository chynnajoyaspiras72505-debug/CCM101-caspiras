# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

I recommend AWS for the startup company because it provides flexible and scalable cloud services that can support a new mobile application. The company can begin with only the resources it needs and scale as the number of users increases. AWS also provides managed services that can reduce the amount of infrastructure the small team needs to maintain. This makes it suitable for a startup expecting rapid growth while managing its resources carefully.

### Recommended Services
- **Amazon EC2** – Provides virtual servers for application workloads.
- **Amazon S3** – Stores application files, media, and backups.
- **Amazon RDS** – Provides a managed relational database for application data.

---

## Client B – University

### Recommended Platform: Microsoft Azure

I recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure integrates closely with Microsoft's existing technologies, which can make cloud migration and identity management easier. It also supports hybrid cloud environments, allowing the university to keep some systems on-premises while moving selected services to the cloud. This provides a practical migration path without replacing the university's entire existing environment.

### Recommended Services
- **Azure Virtual Machines** – Hosts Windows or Linux server workloads in the cloud.
- **Microsoft Entra ID** – Provides cloud-based identity and access management.
- **Azure Blob Storage** – Provides scalable storage for files, backups, and other data.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

I recommend Google Cloud Platform because the company develops artificial intelligence and machine learning applications that require high-performance computing. GCP provides specialized AI and machine learning tools together with scalable computing infrastructure. Its data analytics services are also useful for processing the large datasets commonly required for AI research. These capabilities make GCP well suited for research and machine learning workloads.

### Recommended Services
- **Vertex AI** – Provides tools for building, training, and deploying machine learning models.
- **Compute Engine** – Provides scalable virtual machines for computing workloads.
- **BigQuery** – Provides large-scale data analytics for research datasets.

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

I recommend AWS because the e-commerce company needs highly available infrastructure, global reach, and automatic scaling. AWS provides services that can distribute traffic and adjust computing capacity as customer demand changes. Its global infrastructure can also help the company serve customers from different geographic locations. These capabilities support the reliability and scalability required by a multinational e-commerce application.

### Recommended Services
- **Amazon EC2** – Provides compute capacity for the e-commerce application.
- **Elastic Load Balancing** – Distributes incoming application traffic across resources.
- **Amazon EC2 Auto Scaling** – Automatically adjusts compute capacity according to demand.

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Offers flexible, scalable services and a broad range of tools suitable for growing applications. |
| Enterprise Organization | Microsoft Azure | Provides strong enterprise and hybrid-cloud capabilities with extensive Microsoft integration. |
| Microsoft Environment | Microsoft Azure | Integrates closely with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft technologies. |
| AI / Machine Learning | Google Cloud Platform | Provides strong AI and machine learning services such as Vertex AI and advanced data analytics tools. |
| Kubernetes Deployment | Google Cloud Platform | GKE provides a mature managed Kubernetes platform based on Google's experience with Kubernetes. |
