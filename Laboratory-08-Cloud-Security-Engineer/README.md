# Laboratory 08 - Cloud Security Engineer

## Mission Overview

This mission focuses on securing an Ubuntu web server using a host-based firewall. The activity demonstrates security auditing, the Default Deny policy, SSH protection, and granular port management for a web application.

## Objectives

- Understand the Principle of Least Privilege and Attack Surface.
- Audit active network services and ports.
- Configure UFW using a Default Deny policy.
- Allow SSH and web traffic on port 8080.
- Document firewall security practices using Markdown.
