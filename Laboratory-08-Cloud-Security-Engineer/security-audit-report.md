# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and services only the permissions they need to perform their required tasks. This is important for cloud user accounts because limiting permissions can reduce the damage that could happen if an account is compromised.

## Attack Surface

An attack surface is the collection of possible entry points that an attacker could use to access or affect a virtual machine. Open ports, running services, and unnecessary applications can increase the attack surface and create more opportunities for attacks.

## Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This is safer because the administrator only needs to allow legitimate services instead of trying to identify and block every possible malicious connection.
