# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving a user or service only the permissions needed to perform its required tasks. It is important for cloud user accounts because limiting permissions reduces the possible damage if an account is compromised.

## Attack Surface

The attack surface is the collection of entry points that an attacker could potentially use to access or affect a virtual machine. Open ports, running services, and unnecessary applications can increase the attack surface.

## Default Deny Policy

A Default Deny policy blocks incoming traffic unless a specific firewall rule allows it. This is safer because administrators only need to allow legitimate services instead of trying to identify and block every possible malicious connection.
