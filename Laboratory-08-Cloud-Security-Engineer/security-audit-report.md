# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and services only the permissions they need to perform their tasks. It is important for cloud user accounts because limiting permissions reduces the possible damage if an account is compromised.

## Attack Surface

An attack surface is the collection of points where an attacker could try to access or compromise a virtual machine. Open ports, running services, applications, and exposed network connections can increase the attack surface.

## Default Deny Policy

A Default Deny policy blocks incoming traffic unless a specific rule allows it. This is safer because only required services are exposed instead of trying to identify and block every possible attacker.
